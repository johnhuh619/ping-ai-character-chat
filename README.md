## 어떤 서비스인가요

흔한 AI 캐릭터챗은 대화가 자유로운 대신 목표나 진척감이 약하고, 전통적인 연애 시뮬레이션은 목표가 분명한 대신 정해진 선택지만 고를 수 있습니다. 이 서비스는 두 가지를 합쳤습니다.

- 사용자는 선택지 없이 **자유롭게 말합니다.**
- 캐릭터는 자기 성격과 현재 관계에 맞게 반응합니다.
- 게임은 사용자 말의 의미를 해석해 관계를 변화시킵니다.
- 챕터마다 장소와 관계 목표가 있고, 정해진 턴 안에 목표를 달성하면 다음 단계로 넘어갑니다.

플레이는 **친해지기 → 썸타기 → 고백하기** 세 챕터로 이어지고, 이전 챕터에서 나눈 대화를 캐릭터가 기억한 채로 다음 챕터가 시작됩니다. 모든 챕터를 통과하면 캐릭터와 자유롭게 대화하는 영상통화 모드가 열립니다. 한국어, 영어, 일본어를 지원합니다.

## 담당 역할

- 캐릭터 대화 생성과 관계 판정을 맡는 대화 서버(chat service) 설계 및 개발
- 캐릭터·챕터 콘텐츠를 버전 단위로 관리하고 배포하는 체계 구축
- 한국어·영어·일본어 다국어 콘텐츠 운영

## 핵심 설계

**LLM은 표현하고, 엔진은 결정한다.**
AI가 점수나 성공 여부를 직접 정하면 결과가 매번 흔들리고 "정답 문장"으로 공략하기 쉬워집니다. 그래서 역할을 나눴습니다.

| 구성 요소 | 역할 |
|---|---|
| 대사 생성 모델 | 캐릭터 성격에 맞는 대사를 빠르게 만들어 사용자에게 먼저 보여 줌 |
| 평가 모델 | 출력된 대화를 비동기로 읽고 관계 변화 후보를 제안 |
| 관계 엔진 (규칙 기반) | 제안을 받아 캐릭터 설정, 반복 감쇠, 단계별 상한을 적용해 실제 결과를 결정 |

이 구조 덕분에 응답 속도를 유지하면서도, 같은 입력에는 항상 같은 판정이 나옵니다. 같은 칭찬을 반복하면 효과가 줄어들고, 급하게 들이대거나 압박하는 말은 호감 상승으로 오판되지 않습니다.

**콘텐츠 버전 관리.** 캐릭터 설정, 프롬프트, 챕터 정의를 한 번 발행하면 수정하지 않고 새 버전을 만듭니다. 덕분에 어떤 버전이 어떤 결과를 냈는지 추적하고 비교할 수 있습니다.

**정산의 정확성.** 챕터가 끝나면 아직 처리 중인 평가가 모두 반영될 때까지 기다린 뒤 결과를 정합니다. 기다리다 시간이 초과되면 결과를 추측하지 않고 오류로 처리합니다.
